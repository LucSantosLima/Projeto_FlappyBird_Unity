# Flappy Bird - Unity

Projeto inspirado em **Flappy Bird**, desenvolvido em **Unity com C#** durante meus estudos de desenvolvimento de jogos.

O objetivo do projeto foi praticar conceitos fundamentais da Unity, como física 2D, colisões, prefabs, interface, geração de obstáculos e gerenciamento do estado do jogo.

## 🎮 Funcionalidades

- Movimentação do jogador utilizando `Rigidbody2D`
- Sistema de pulo com física
- Detecção de colisões
- Sistema de Game Over
- Reinício da partida
- Obstáculos gerados automaticamente
- Posição vertical aleatória dos obstáculos
- Sistema de pontuação
- Aumento progressivo da dificuldade
- Pausa completa do jogo ao perder

## 📚 Conceitos praticados

Durante o desenvolvimento deste projeto, pratiquei conceitos como:

- `Rigidbody2D` e física 2D
- `Collider2D` e Triggers
- Tags e `CompareTag`
- Prefabs
- `Instantiate` e `Destroy`
- `Time.deltaTime`
- `Time.timeScale`
- Manipulação de UI com TextMeshPro
- Comunicação entre scripts
- Gerenciamento de cenas com `SceneManager`
- Geração aleatória com `Random.Range`
- Controle progressivo de dificuldade
- Versionamento com Git
